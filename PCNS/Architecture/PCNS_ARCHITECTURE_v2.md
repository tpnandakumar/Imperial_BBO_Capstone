# PCNS Architecture v2

## Status

Architecture baseline frozen before the next experimental cycle.

## Scientific position

The Pisharam Computational Nervous System (PCNS) is a computational architecture inspired by the functional organisation of biological nervous systems. It is not presented as a literal digital reconstruction of neuroanatomy. Its purpose is to generate testable hypotheses about computational accuracy, reliability, stability, energy efficiency, regenerative resource use and cost efficiency.

## Executive computational layer

The Executive Computational Cortex comprises:

- Cognitive Array Cortex
- Limbic Computational System

The Cognitive Array Cortex provides reasoning, planning, perception, memory, language, abstraction, creativity and decision support. The Limbic Computational System provides salience, priority, value, persistence, novelty weighting and adaptive motivational bias.

## Dual parallel control systems

Two principal control systems operate in parallel:

1. A-DMIC, the Adaptive Dynamic Milieu Intérieur, regulates the internal computational environment.
2. PCC, the Pyramidal Computational Control pathway, regulates computational intent, initiation and directed execution.

Neither is subordinate to the other. They may share information, augment one another or act independently.

## Functional pathway organisation

### Driving pathway

The pyramidal computational pathway provides the primary directed drive for action, task execution and controlled computational output.

### Correcting and co-ordinating pathway

The extrapyramidal-inspired pathway provides selection, gating, inhibition, excitation, prediction, timing, correction, equilibrium and trajectory control. Basal ganglia and cerebellar functions are treated as parallel contributors rather than a direct serial chain.

### Relaying and executing pathway

The thalamic and brainstem-inspired system provides relay, prioritisation, integration, sequencing, distribution and execution. In one possible architecture, the thalamus and brainstem form the apex of an inverted computational pyramid. This is an engineering abstraction for efficiency testing, not a mandatory or literal anatomical claim.

## Forward and reverse control

PCNS uses descending control and ascending reverse feedback. Feedback is multilevel and should be handled at the lowest competent level before escalation.

Feedback levels:

1. Local execution correction
2. Correcting and co-ordinating regulation
3. A-DMIC and PCC reciprocal control
4. Executive cognitive revision

## Balanced control objective

The system must prevent both:

- uncontrolled overdrive
- underperformance caused by insufficient information, excessive inhibition or inadequate resource allocation

The target is an Optimal Computational Operating Zone rather than maximum or minimum activity.

## Second-level learning control

A second control level regulates model learning quality and generalisation. It monitors underfitting and overfitting using training, validation and test evidence, uncertainty, model complexity, feature use and stability across datasets.

## Governing principle

PCNS combines dual parallel control, multilevel reverse feedback and layered learning control so that computational activity remains purposeful, informed, stable, efficient and generalisable.
