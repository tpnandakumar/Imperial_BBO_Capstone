# PGC Experiment 008CM: Basal Ganglia Modulation and Integration

## Status

Planned and initialised. No experimental results are claimed yet.

## Purpose

Experiment 008CM evaluates whether a biologically inspired basal ganglia regulatory layer can improve accuracy targeting while reducing overfitting, underfitting, oscillation and unstable candidate switching.

The experiment preserves the A-DMIC Computational Milieu Intérieur, PCEEC framework, PFRAMOS and PGC integration.

## Core regulatory pathways

1. **Direct pathway**: facilitates candidate pathways that demonstrate improving validation performance, generalisation, stability and efficiency.
2. **Indirect pathway**: suppresses candidate pathways that demonstrate overfitting, excessive complexity, instability, poor generalisation or inefficient resource use.
3. **Hyperdirect pathway**: applies an immediate global brake when deterministic constraints, catastrophic instability, leakage or incoherent A-DMIC states are detected.

## Computational nuclei mapping

- Striatum: candidate-state and evidence intake
- GPe: ongoing inhibitory regulation
- GPi/SNr: final output gating
- STN: rapid global brake
- SNc analogue: adaptive confidence modulation
- Thalamic return analogue: gated re-entry into the active PGC computational cortex

## Experimental arms

- Reference optimiser without basal ganglia modulation
- Direct-pathway-only facilitation
- Direct plus indirect modulation
- Full direct, indirect and hyperdirect modulation
- Full modulation with adaptive confidence control

## Primary questions

1. Does excitatory and inhibitory modulation reduce overfitting?
2. Does release from excessive inhibition reduce underfitting?
3. Does adaptive modulation improve protected-test accuracy targeting?
4. Does hyperdirect braking reduce unstable or unsafe transitions?
5. Can these gains be achieved without unacceptable latency, memory or cost penalties?

## Primary outcome domains

- Accuracy and calibration
- Reliability and repeatability
- Stability and oscillation control
- Generalisation gap
- Computational efficiency
- Software resource regeneration
- Normalised compute cost
- A-DMIC milieu preservation

## Evidence boundary

This experiment will test a computational architecture inspired by basal ganglia organisation. It will not claim biological equivalence or clinical validity. No result will be recorded until the executable experiment has run and its exact CSV and JSON artefacts have been preserved.
