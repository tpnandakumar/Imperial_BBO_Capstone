# Protocol: 008CM Basal Ganglia Modulation and Integration

## Hypothesis

A balanced excitatory and inhibitory regulatory layer will reduce overfitting and underfitting, improve protected-test accuracy targeting, damp oscillation and preserve PCEEC efficiency better than ungated or permanently excited candidate selection.

## Design

Use fresh seeds and temporally separated training, validation and protected-test partitions. Candidate models must be identical across arms. Only the regulatory mechanism may differ.

## Arms

| Arm | Direct | Indirect | Hyperdirect | Adaptive confidence |
|---|---:|---:|---:|---:|
| Reference | No | No | No | No |
| Direct only | Yes | No | No | No |
| Balanced modulation | Yes | Yes | No | No |
| Full brake | Yes | Yes | Yes | No |
| Full adaptive | Yes | Yes | Yes | Yes |

## Regulatory signals

### Excitatory signal

Increase pathway facilitation when validation accuracy, calibration, stability and efficiency improve without widening the generalisation gap.

### Inhibitory signal

Increase pathway suppression when training performance improves while validation performance worsens, complexity rises without protected-test benefit, oscillation increases, or resource cost becomes disproportionate.

### Hyperdirect signal

Immediately inhibit release when deterministic constraints fail, memory or worker leakage is detected, A-DMIC coherence falls outside the permitted range, or candidate switching becomes catastrophically unstable.

### Adaptive confidence signal

Update candidate confidence gradually from repeated evidence. Prohibit winner-takes-all jumps unless the hyperdirect safety route requires immediate suppression.

## Overfitting indicators

- training-validation accuracy gap
- training-validation loss gap
- protected-test degradation
- excess complexity per unit validation gain
- instability across seeds

## Underfitting indicators

- persistently low training and validation performance
- premature plateau
- insufficient active model capacity
- excessive inhibitory load
- failure to exploit validated specialist capacity

## Accuracy-targeting indicators

- mean protected-test accuracy
- minimum protected-test accuracy
- calibration error
- log loss
- distance from a predeclared accuracy target

## Stability indicators

- variance across seeds
- switching frequency
- oscillation amplitude
- emergency-brake activation rate
- unresolved violation release rate

## PCEEC indicators

- CPU time
- latency
- throughput
- active model count
- RSS-time proxy
- memory recovery ratio
- worker-thread leak rate
- normalised compute cost index

Electrical energy and direct monetary cost must not be claimed unless directly measured.

## Success criteria

The full adaptive arm should:

1. reduce generalisation error relative to the reference arm;
2. reduce both overfitting and underfitting events;
3. improve or preserve protected-test accuracy;
4. reduce oscillation and unstable switching;
5. release no unresolved deterministic violation;
6. preserve A-DMIC Computational Milieu Intérieur;
7. remain within a predeclared PCEEC compute-cost tolerance.

## Evidence boundary

This protocol defines the intended test. It is not itself experimental evidence. Results must be generated by the executable runner and preserved exactly before any performance claim is made.
