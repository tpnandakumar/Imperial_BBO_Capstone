# Propagating Sphere of Influence

## Status

Core field architecture for the Ripple Controller, Delta Bridge Sensors and Dynamic Burst Field Control.

## Core proposition

A computational burst should not be modelled only as a point or line signal. It should create a propagating sphere of influence around the active wave front.

The sphere defines the region within which the burst can alter routing, recruit specialists, modulate confidence, change viscosity, capture residual waves, amplify useful signals and damp harmful interference.

## Field geometry

```text
burst origin
        ↓
expanding influence sphere
        ↓
wave-front surface
        ↓
local recruitment and modulation zone
        ↓
contracting recovery sphere
        ↓
strategic diastolic reset
```

## Dynamic radius

The sphere radius should vary with:

- pulse intensity
- pulse frequency
- local viscosity
- pressure gradient
- tunnel aperture
- predicted information gain
- phase coherence
- specialist availability
- congestion
- recovery state

The sphere should expand only while expected Net Sphere Gain remains positive.

## Anisotropic propagation

The influence field should not always remain perfectly spherical.

When a target specialist or anterior chamber lies in a preferred direction, the field should become anisotropic and extend further along the selected vector while remaining constrained elsewhere.

```text
isotropic state
→ equal influence in all directions

vectorised state
→ elongated influence towards selected target
→ reduced lateral spread
```

## Surface-sensor shell

The outer boundary of the sphere should act as a moving sensor shell.

It should measure:

- local confidence change
- entropy change
- phase alignment
- pressure attenuation
- wave reflection
- viscosity mismatch
- specialist correction probability
- specialist harm probability
- congestion
- residual uncertainty

## Delta Bridge integration

Paired sensors should be positioned across the moving sphere.

```text
inner-shell sensor
+
outer-shell sensor
→ radial delta

upstream-shell sensor
+
downstream-shell sensor
→ axial delta

left-shell sensor
+
right-shell sensor
→ lateral delta
```

The Ripple Controller should integrate these deltas to estimate whether the sphere is expanding coherently, distorting, fragmenting or collapsing.

## Wave capture

The sphere may capture an existing coherent wave when:

- phase difference is within a validated range
- direction is compatible with the target vector
- expected amplification gain is positive
- reflection risk is low

Captured waves should be phase-aligned before amplification.

## Selective amplification

Amplification should occur only within the part of the sphere containing useful signal.

The controller should amplify:

- coherent specialist evidence
- confidence-improving residuals
- entropy-reducing corrections
- validated cached states

It should damp:

- destructive interference
- phase-opposed waves
- high-harm specialist signals
- redundant or stale states

## Recruitment field

Any specialist territory entering the sphere may be recruited when its expected Net Specialist Gain is positive.

Recruitment strength should depend on:

- distance from the wave front
- directional alignment
- predicted correction probability
- activation cost
- latency
- local congestion

## Vectoring

The sphere should carry a directional control vector.

```text
influence vector
=
preferred target direction
×
phase coherence
×
expected gain
×
pressure support
```

The vector should steer the strongest part of the wave front towards the selected specialist or anterior decision chamber.

## Dynamic dampening shell

The trailing boundary of the sphere should form a dampening shell.

Its functions are:

- absorb reflected waves
- increase local viscosity during recovery
- prevent secondary uncontrolled bursts
- close specialist routes after correction
- return residual state through the outer venous pathway
- restore the stable interior

## Sphere interaction

Multiple spheres may:

- merge when phase and target are compatible
- remain separate when uncertainty domains differ
- repel when they carry contradictory specialist signals
- cancel when phase opposition predicts harm
- queue when tunnel capacity is limited

## Net Sphere Gain

```text
Net Sphere Gain
=
corrected errors
-
newly introduced errors
-
field-expansion cost
-
recruitment cost
-
phase-instability cost
-
dampening and recovery overhead
```

## Priority statement

The propagating sphere of influence converts a burst from a local command into a controlled moving field. Its purpose is to recruit and amplify only the computational territory that can improve the decision, while dynamically limiting spread, interference and recovery cost.
