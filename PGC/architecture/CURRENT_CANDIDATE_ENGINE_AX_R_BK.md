# Current Candidate Engine: AX-R-BK

## Status

AX-R-BK is the current best candidate engine identified by the completed comparative experiments.

This designation means:

- best overall architecture among the systems compared so far
- strongest Architecture Value Index in Experiment 008BP
- strongest pairwise hybrid in Experiment 008BO
- candidate for fresh-seed and unseen-dataset confirmation

It does not yet mean universal or final confirmatory superiority.

## Architecture

AX-R-BK combines:

```text
AX-R sparse adaptive pathway
+
BK regenerative stable-core stochastic-dropout pathway
```

### AX-R contribution

- sparse adaptive stack selection
- low operational model count
- high avoided-model fraction
- strong cache reuse
- high regenerative-use efficiency
- preservation of high-accuracy sparse configurations

### BK contribution

- stable model core
- stochastic peripheral specialist recruitment
- regenerative reward during development selection
- stronger state reuse
- recovery-aware computational reuse
- reduced interference from unnecessary active models

## Candidate operating principle

```text
Maintain a sparse validated interior.
Recruit specialists only when development evidence supports them.
Reuse coherent computational states.
Avoid unnecessary model activation.
Preserve recovery capacity without increasing uncontrolled complexity.
```

## Evidence

### Experiment 008BO

AX-R + BK was the strongest of four pairwise regenerative hybrids.

- mean accuracy: 0.984650
- maximum accuracy: 0.996296
- minimum accuracy: 0.968080
- mean worst-dataset accuracy: 0.974816
- macro-F1: 0.984403
- balanced accuracy: 0.983886
- mean active models: 3.383
- dropout fraction: 0.661667
- cache reuse rate: 0.996079
- Net Regenerative Efficiency: 0.819201

AX-R + BK significantly outperformed AX-R + BJ:

- mean difference: +0.000568
- Holm-adjusted p value: 0.011063

The four-system Friedman test was not significant, so global superiority across all four pairwise systems was not established.

### Experiment 008BP

AX-R + BK ranked first in the combined Accuracy, Versatility, Regenerative Use and Complexity analysis.

- Architecture Value Index: 77.8642
- Accuracy Index: 92.1553
- Versatility Index: 85.8775
- Regenerative Use Index: 72.5344
- Combined Complexity Index: 51.8319
- Versatility Efficiency Quotient: 1.6568

Classification:

```text
Complexity < Versatility
```

## Validation boundary

The current evidence is comparative and repeatedly evaluated on the breast cancer, wine and digits datasets using the preserved AY fresh-seed evaluation space.

The next required step is confirmatory testing on:

- fresh unseen seeds
- untouched holdouts
- additional dataset families
- fixed candidate budgets
- predeclared success criteria

Electrical energy was not measured. Regenerative efficiency remains a computational reuse proxy.
