# Limbic-Autonomic Cardiovascular Cortex Architecture

## Status

Concept architecture derived from Experiments 008AR, 008AS, 008AT and 008AU. This document defines the intended integration between the Cortex cognitive network and the autoregulated computational cardiovascular support system.

## Core proposition

The Cortex determines what must be processed.

The limbic layer determines significance, urgency and salience.

The autonomic gateway converts that significance into regulated computational demand.

The cardiovascular network delivers model influence, validation flow and computational resources to the regions that require them.

## Integrated pathway

```text
Cortex cognitive network
        ↓
limbic appraisal and salience
        ↓
hypothalamic-autonomic computational gateway
        ↓
autoregulated computational heart
        ↓
arterial-style influence conduits
        ↓
regional vascular distribution
        ↓
specialist cognitive and predictive regions
        ↓
venous-style return of uncertainty, load and error
        ↓
limbic and cortical recalibration
```

## Cortex cognitive network

The Cortex layer is responsible for:

- perception
- reasoning
- memory
- planning
- decision-making
- creative integration
- cross-domain cognition
- specialist predictive processing

The Cortex must express computational demand but should not directly control every vascular variable.

## Limbic integration layer

The limbic layer acts as the significance and urgency interpreter.

It evaluates:

- uncertainty
- disagreement
- low consensus confidence
- reward relevance
- threat or risk
- conflict
- memory relevance
- urgency
- sustained attention
- cognitive fatigue

These signals form a limbic salience state.

## Autonomic gateway

The autonomic gateway translates limbic salience into bounded support commands.

It regulates:

- pulse frequency
- pulse pressure
- resource allocation gain
- regional vasodilation
- local vasoconstriction
- recovery to baseline
- protection against runaway model dominance
- protection against global under-supply

## Autoregulated computational heart

The heart is a pulsatile control mechanism rather than a fixed pump.

Its operating state should vary with activity:

```text
low activity
→ basal heart rate and pulse pressure

rising validated demand
→ moderate increase in rate and pressure

high uncertainty or turbulence
→ bounded compensatory response

stagnation
→ brief increase in drive

recovery
→ return towards baseline
```

The heart must avoid computational equivalents of hypertension, shock and arrhythmia.

## Vascular architecture

### Arterial conduits

Carry high-priority validated influence towards active cognitive regions.

### Capillary microcirculation

Distributes fine-grained model contribution, validation support and specialist attention at sample level.

### Venous return

Returns:

- uncertainty
- prediction error
- unresolved conflict
- computational load
- congestion
- fatigue
- thermal and turbulence state

These return signals modify the next autonomic response.

## Demand-linked perfusion

Computational flow must follow validated cognitive demand.

A region receives increased supply only when demand is persistent across development folds, datasets or bootstrap samples.

A single high score must not create permanent vasodilation.

## Normotensive control bounds

The system must preserve minimum and maximum flow bounds.

Minimum flow prevents model starvation.

Maximum flow prevents one model or cognitive region from monopolising the stack.

Recovery continuously returns flow towards baseline when salience falls.

## Relationship to Pandora and RIPPLE

The integrated architecture unifies the prior mechanisms:

- RIPPLE becomes pulse propagation
- MaxInflu becomes demand-prioritised perfusion
- peristaltic recoil becomes vascular contraction and propulsion
- pressure gradient becomes directed flow
- density becomes inertia
- viscosity becomes resistance
- lubrication becomes reduced directional friction
- temperature becomes activity-state regulation
- gearbox ratio becomes transmission efficiency
- the pear field becomes the asymmetric closed search chamber

## Current evidence boundary

Experiment 008AU reproduced the 0.988596 protected-test peak by configuration 4 using limbic-autonomic reliability gating.

The result improved search efficiency but did not cross 0.99.

The architecture is therefore supported as an efficient regulatory layer, not yet as evidence of a higher predictive ceiling.

## Next implementation direction

The cardiovascular system should next support specialist microcirculation.

Difficult samples should be routed to specialist learners trained on distinct error phenotypes, while the autonomic layer regulates when and how strongly those specialists receive computational flow.

This is the most credible route to increasing predictive capacity beyond the current plateau because it adds new information processing rather than only redistributing the same seven model outputs.
