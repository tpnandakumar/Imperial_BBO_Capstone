# Black Box Resolution research data

This is the canonical Black Box Resolution (BBR) location for the numerical tables produced by the earlier research sequence. The original files used the working label Black Box Decryption (BBD). The assessment-facing name is now BBR, so the retained tables have been copied here with clear BBR filenames while the historical source files remain available for reproducibility.
