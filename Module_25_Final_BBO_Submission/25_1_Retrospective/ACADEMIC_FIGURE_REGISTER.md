## Reproduction

Run:

```bash
python Module_25_Final_BBO_Submission/25_1_Retrospective/generate_academic_infographics.py
```

The script recreates the complete numbered figure set in `academic_infographics/`. It reads only repository-held project data and experiment outputs. Course-page screenshots are not used.
