# Module 25: Final BBO Capstone Submission

## Assessment evidence hub

Module 25 is the final assessment stage following completion of the thirteen authorised BBO rounds. It is not another optimisation round and does not create Week 14 or Week 25 BBO observations.

This section is organised around the three assessed Module 25 components:

1. **Component 25.1: Retrospective on the BBO capstone project**
2. **Component 25.2: Successful optimisation strategies**
3. **Final submission 25.3: Submitting the GitHub repository**

The Component 25.1 and 25.2 discussion-board responses have been completed from the released Imperial prompts and verified repository evidence. Component 25.3 provides the final assessor-facing repository route.
