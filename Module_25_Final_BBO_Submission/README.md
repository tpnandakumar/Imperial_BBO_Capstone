# Module 25: Final BBO Capstone Submission

## Assessment evidence hub

Module 25 is the final assessment stage following completion of the thirteen authorised BBO rounds. It is not another optimisation round and does not create Week 14 or Week 25 BBO observations.

This section is organised around the three assessed Module 25 components:

1. **Component 25.1: Retrospective on the BBO capstone project**
2. **Component 25.2: Successful optimisation strategies**
3. **Final submission 25.3: Submitting the GitHub repository**

The actual 25.1 and 25.2 responses will be prepared only after the corresponding Imperial prompts and rubrics are available. Until then, this folder provides an evidence structure rather than pre-empting the assessed questions.

The `Advanced_Extension_Series`, including SOC, the Surrogate Optimisation Competition, begins only after the assessed thirteen-round BBO experiment. It is additional research. It was not used to generate the historical Week 01 to Week 13 outputs and it does not retrospectively alter those results.
