# Week 10 Changelog

This changelog records documentation and analytical changes made to the Week 10 folder. It does not alter the historical competition inputs or returned outputs.

## Original Week 10 record

The Week 10 folder was established with the verified submitted inputs, returned objective values, 15 section analysis README, analytical summary, figure data summary, analysis code and figure generation code.

The authoritative source files are:

- `week_10_inputs.csv`
- `week_10_results.csv`

## Documentation expansion

Following the more detailed documentation approach developed for Week 09, Week 10 was expanded to include:

- `DATASHEET.md`
- `MODEL_CARD.md`
- `DATASET.md`
- `ASSUMPTIONS.md`
- `VALIDATION.md`
- `DECISION_CARD.md`
- `CHANGELOG.md`

The README was also updated with direct links to the datasheet and model card so that assessors can move from the weekly analysis to the formal documentation without searching the folder manually.

## Week specific adaptations

The Week 10 documentation was not copied mechanically from Week 09. It was adapted to the new evidence available after the tenth optimisation round.

The principal additions were:

1. explicit documentation of the exact repeatability observation for Function 5;
2. separation of objective improvement from information gain;
3. documentation of failed local movement in Function 4 as evidence supporting reassessment;
4. recognition that Functions 7 and 8 remained positive while showing small declines;
5. continued classification of Function 1 as unresolved near zero;
6. a clearer decision record linking Week 10 evidence to the verified Week 11 query set;
7. explicit assumptions and validation boundaries to prevent later research developments from being attributed retrospectively to Week 10.

## Numerical integrity

No submitted input or returned output was changed during the documentation expansion. Numerical values were preserved exactly from the verified CSV source files. Derived differences use exact decimal arithmetic where recorded.

## Assessment purpose

The expansion brings Week 10 into closer alignment with the richer Week 09 assessment record while preserving the chronological development of the project. The additional files are intended to make provenance, assumptions, validation, decision making and limitations visible to an assessor rather than leaving those elements implicit in the main README.
