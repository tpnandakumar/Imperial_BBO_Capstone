## Functional integration

### PACC cognitive layer

Defines and computes:

- orientation and cognitive context
- attention
- working memory
- episodic encoding and retention
- semantic cognition
- retrieval and recall
- language
- executive control
- abstraction
- visuospatial cognition
- naming and object knowledge
- social and behavioural regulation
- metacognition

### PIMF diagnostic layer

PIMF analyses change in every cognitive domain through:

```text
D
ΔD
Δ²D
Δ³D
ΔⁿD
```

It identifies emerging, dominant, plateauing, reversing, oscillating and boundary cognitive states.

### PFRAMOS regulatory layer

PFRAMOS selects and regulates the most coherent developmental or corrective conduit.

Examples include:

- attention regulation
- semantic reconstruction
- memory consolidation
- cue-supported retrieval
- visuospatial reconfiguration
- executive inhibition
- strategy switching
- confidence recalibration

### BBO engine

The BBO engine provides a controlled sequential environment for testing:

- selective attention to dimensions
- state retention
- adaptive forgetting
- semantic route formation
- hypothesis generation
- counterfactual search
- cognitive flexibility
- retrieval efficiency
- metacognitive calibration

Private candidate coordinates and protected outputs remain isolated.

## Schooling integration

PACC uses the concurrent schooling architecture with separate lanes for:

- attention and working memory
- episodic and semantic memory
- language and fluency
- executive and abstraction
- visuospatial cognition
- social and behavioural cognition
- metacognition

Each lane requires its own dataset snapshot, checkpoint, protected test, training log and regression report.

## Training-result integration

Every cognitive experiment must write a reproducible result record containing:

- PACC domain
- source data and data form
- mathematical model version
- training and protected-test metrics
- PIMF influence states
- PFRAMOS conduit decision
- compute and energy record
- bias and uncertainty analysis
- publication eligibility

## Publication integration

PACC becomes a dedicated publication series within the wider PFRAMOS programme.

Planned papers include:

1. PACC foundations and mathematical cognitive state model
2. Computational memory as attention, semantics, retention and retrieval
3. Computational semantic cognition
4. Computational visuospatial cognition
5. Executive control, abstraction and cognitive flexibility
6. Social cognition, behaviour and metacognition
7. Acquired cognitive development through concurrent schooling
8. Integrated PACC evaluation across BBO and independent datasets

## Activation boundary

The architecture is active for development, modelling, testing and shadow evaluation.

No claim of human-equivalent cognition, clinical diagnosis or superior cognitive performance is permitted without controlled, reproducible evidence.

## Governing statement

PACC acquires and integrates computational cognitive abilities. PIMF diagnoses their development, PFRAMOS regulates their pathways, and the BBO engine provides a controlled environment for testing their behaviour.
