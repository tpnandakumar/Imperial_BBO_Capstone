# TMLR Submission Readiness Checklist

## A. Scientific contribution

- [ ] The research question is explicit.
- [ ] The primary hypothesis was specified before final testing.
- [ ] The claimed contribution is distinct from PIMF, HEBO and the established BBO strategy.
- [ ] All Pisharamised components preserve original-method lineage.
- [ ] Claims are no broader than the evidence.

## B. Data and provenance

- [ ] Every dataset has a stable identifier, source, licence, version and hash.
- [ ] Project-owned and external datasets are clearly distinguished.
- [ ] Temporal order is preserved where required.
- [ ] Training, validation and protected-test data are separated.
- [ ] Benchmark contamination checks are complete.
- [ ] Duplicate and near-duplicate records are removed or reported.
- [ ] Privacy and sensitive-data review is complete.

## C. Experimental design

- [ ] Baselines are implemented fairly.
- [ ] PFRAMOS version is frozen.
- [ ] Hyperparameters and seeds are recorded.
- [ ] Ablation studies isolate major components.
- [ ] Failure criteria and stopping rules are documented.
- [ ] Independent datasets cover more than one data form.
- [ ] Prospective or shadow validation is complete.

## D. Results

- [ ] Primary outcome is reported with uncertainty.
- [ ] Negative and inconclusive results are included.
- [ ] Robustness and perturbation tests are complete.
- [ ] Calibration and uncertainty are measured.
- [ ] Bias and representation analyses are complete.
- [ ] Compute, memory, runtime and energy proxies are reported.
- [ ] Statistical assumptions are checked.
- [ ] Multiple-comparison handling is documented where applicable.

## E. Reproducibility

- [ ] Every result links to a training-result record.
- [ ] Training-log hash chain verifies.
- [ ] Code version and environment are frozen.
- [ ] Dataset manifests are complete.
- [ ] Supplementary files are anonymised.
- [ ] Reproduction instructions run from a clean environment.
- [ ] Private BBO candidate coordinates are excluded.

## F. TMLR format and policy

- [ ] Official TMLR LaTeX template is used without layout alteration.
- [ ] Main manuscript is anonymised.
- [ ] Supplementary material is anonymised and within the allowed format and size.
- [ ] All authors have complete, active OpenReview profiles.
- [ ] Authorship criteria are satisfied.
- [ ] Funding and conflicts are disclosed through the submission system.
- [ ] Ethics and broader-impact considerations are addressed.
- [ ] LLM-assisted preparation has been checked for accuracy, originality and citation integrity.
- [ ] No prohibited simultaneous submission exists.

## G. Final internal approval

- [ ] Methodological review passed.
- [ ] Statistical review passed.
- [ ] Reference verification passed.
- [ ] Figure and table data verification passed.
- [ ] Reproducibility review passed.
- [ ] Author approval obtained.
- [ ] Manuscript moved to `submission_ready`.
