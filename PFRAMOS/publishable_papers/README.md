# PFRAMOS Publishable Papers

## Purpose

This folder contains submission-ready manuscripts derived from validated PFRAMOS experiments and training results.

## Structure

```text
PFRAMOS/publishable_papers/
├── candidates/
├── under_internal_review/
├── submission_ready/
├── submitted/
├── revisions/
├── supplementary_material/
├── figures/
├── tables/
└── references/
```

## Required manuscript sections

Every paper must contain:

1. Title
2. Authors and affiliations
3. Abstract
4. Keywords
5. Introduction
6. Research question or hypothesis
7. Methodology
8. Data and provenance
9. Experimental design
10. Results
11. Bias, robustness and uncertainty analysis
12. Discussion
13. Limitations
14. Conclusion
15. Data and code availability
16. Ethics, licence and conflict-of-interest statements
17. References
18. Supplementary material where required

## Evidence rules

- Every numerical claim must link to a reproducible training result.
- No illustrative or invented statistic may be presented as measured evidence.
- External claims must retain source citations.
- Dataset licences and access conditions must be stated.
- Negative and inconclusive findings must not be hidden.
- Pisharamised methods must preserve the lineage of the original method.
- Candidate BBO coordinates and other private live-decision data must not appear in a paper unless explicitly released.

## Submission state

A manuscript becomes `submission_ready` only after passing:

- evidence traceability review
- statistical and methodological review
- bias and contamination review
- reproducibility review
- reference verification
- figure and table verification
- authorship and disclosure review
