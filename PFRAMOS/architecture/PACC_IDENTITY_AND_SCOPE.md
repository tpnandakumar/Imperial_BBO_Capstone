# PACC Identity and Scope

## Formal name

**PACC** means **Pisharam Acquired Computational Cognitive Ability**.

The shorter working name is **AC**, meaning **Artificial Cognition**.

PACC and AC refer to the same developing cognitive architecture unless a later document explicitly distinguishes them.

## Foundational definition

PACC is a mathematically modelled and computationally implemented cognitive architecture that acquires, organises, applies, monitors and improves cognitive abilities over time.

It is not a memory system alone. Memory is one component within a wider cognitive network.

## Level 1 basic scaffold

The Level 1 domain structure is informed by ACE-R, ACE-III and MoCA:

- cognitive context and orientation
- attention and concentration
- working memory
- episodic memory
- semantic memory
- retrieval and recall
- verbal generative access and fluency
- language
- executive control
- abstraction
- visuospatial cognition
- naming and object knowledge

This is only the basic scaffold.

## Extended PACC domains

The complete architecture must also include:

- social cognition
- emotion recognition
- theory of mind
- behaviour and motivation
- person-specific semantic knowledge
- praxis and action sequencing
- calculation
- perceptual processing
- decision-making
- metacognition
- confidence calibration
- adaptive learning
- transfer of learning
- counterfactual reasoning
- cognitive flexibility

## Acquired ability

The word **Acquired** is essential.

PACC does not assume that cognition is fully present at initialisation. Cognitive ability develops through:

- exposure to varied data forms
- domain-specific training
- repeated validation
- cross-domain integration
- error analysis
- adaptive memory
- strategy revision
- metacognitive monitoring
- controlled promotion of improved capability

## Computational state

At time t, the PACC state is represented as a vector of domain states:

```text
C_t = [O_t, A_t, W_t, E_t, S_t, R_t, F_t, L_t, X_t, B_t, V_t, N_t, G_t, M_t]
```

Where:

- O_t is orientation and cognitive context
- A_t is attention
- W_t is working memory
- E_t is episodic encoding and retention
- S_t is semantic cognition
- R_t is retrieval and recall
- F_t is verbal generative access and fluency
- L_t is language
- X_t is executive control
- B_t is abstraction
- V_t is visuospatial cognition
- N_t is naming and object knowledge
- G_t is social, behavioural and goal regulation
- M_t is metacognition

The state transition is:

```text
C_(t+1) = F(C_t, X_t, M_t, U_t, P_t, epsilon_t)
```

Where:

- X_t is new input
- M_t is retrieved memory
- U_t is cognitive control action
- P_t is PFRAMOS regulation
- epsilon_t is uncertainty, noise and conflict

## Relationship with PIMF

PIMF analyses how each cognitive domain changes over time through:

```text
D
ΔD
Δ²D
Δ³D
ΔⁿD
```

This identifies emerging, dominant, plateauing, reversing, oscillating and boundary cognitive states.

## Relationship with PFRAMOS

PFRAMOS selects the most coherent corrective or developmental conduit.

Examples include:

- attention regulation
- semantic reconstruction
- retrieval support
- visuospatial reconfiguration
- executive inhibition
- strategy switching
- confidence recalibration

## Relationship with the BBO engine

The BBO engine provides a controlled environment for testing:

- sequential learning
- state retention
- adaptive forgetting
- hypothesis generation
- counterfactual search
- decision efficiency
- cognitive flexibility
- metacognitive calibration

## Governing statement

PACC is not the simulation of one cognitive test. It is the computational acquisition and integration of multiple cognitive abilities into one auditable adaptive system.
