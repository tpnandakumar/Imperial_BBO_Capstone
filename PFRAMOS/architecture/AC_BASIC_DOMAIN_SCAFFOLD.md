# AC Basic Cognitive Domain Scaffold

## Purpose

ACE-R, ACE-III and MoCA provide a useful first-level map of cognitive domains. They are screening structures, not complete models of cognition. AC therefore uses them as the Level 1 scaffold, then expands each domain into deeper computational modules.

## Clarification

The relevant Addenbrooke instruments are:

- ACE-R, the Addenbrooke's Cognitive Examination Revised
- ACE-III, the third version that followed ACE-R

The core ACE-R and ACE-III domains are:

- attention and orientation
- memory
- verbal fluency
- language
- visuospatial function

The main MoCA domains are:

- visuospatial and executive function
- naming
- attention
- language
- abstraction
- delayed recall
- orientation

## Unified Level 1 AC scaffold

```text
1. Cognitive context and orientation
2. Attention and concentration
3. Working memory
4. Episodic memory
5. Semantic memory
6. Retrieval and recall
7. Verbal generative access and fluency
8. Language
9. Executive control
10. Abstraction
11. Visuospatial cognition
12. Naming and object knowledge
```

## Domain separation

### Cognitive context and orientation

Represents current temporal, spatial, task and self-context.

### Attention and concentration

Regulates selection, maintenance, switching and distractor suppression.

### Working memory

Maintains and manipulates active information.

### Episodic memory

Represents events and their temporal and contextual bindings.

### Semantic memory

Represents concepts, meanings, categories and relationships.

### Retrieval and recall

Measures access to stored representations. Recall is treated as an output, not as the whole memory system.

### Verbal generative access and fluency

Measures constrained search, initiation, strategy, inhibition and lexical or semantic access.

### Language

Includes comprehension, production, repetition, syntax, semantics and pragmatics.

### Executive control

Includes planning, inhibition, switching, sequencing, monitoring and error correction.

### Abstraction

Identifies higher-order relationships, categories, rules and analogies.

### Visuospatial cognition

Represents objects, positions, relations, transformations, construction and spatial coherence.

### Naming and object knowledge

Separates perceptual identification, lexical access, semantic knowledge and verbal output.

## Screening versus full cognition

ACE and MoCA are useful for detecting broad domain weakness. They do not fully cover:

- social cognition
- emotion recognition
- theory of mind
- person-specific semantic knowledge
- behaviour and motivation
- praxis
- calculation
- detailed perceptual processing
- metacognition
- decision-making
- long-term adaptive learning

These domains must be added through the wider Hodges, Neary and Snowden architecture.

## AC hierarchy

```text
Level 1: ACE and MoCA domain screening scaffold
        ↓
Level 2: Component decomposition within each domain
        ↓
Level 3: Error morphology and dependency analysis
        ↓
Level 4: PIMF influence and higher-order delta analysis
        ↓
Level 5: PFRAMOS regulation and corrective conduit selection
        ↓
Level 6: Integrated Artificial Cognition state
```

## Governing rule

A domain score is a screening signal. AC must identify which computational component produced the score and which upstream dependency caused any failure.
